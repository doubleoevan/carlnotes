title: Topic memory claim dates
version: 1
model tier: shared
description: How a topic memory claim keeps its text apart from its event date, spliced into the prompts that propose and split claims.
updated: 2026-11-20
---

Write only the claim in text. Store the event date in factDate at the precision the evidence supports. Use YYYY-MM-DD for a day, YYYY-MM for a month, YYYY for a year, or null if the event date is unknown.
