## Decisions

Write up to five default queries from the existing Topic brief. The first ready search Source handles the allowance for a Scan. Select at most twelve active, undisputed facts, favoring positive ratings and rotating ties by Scan ID. Check up to three citations per fact. Both query terms must occur in the publisher's title or excerpt on the same public external Finding. A Personal source, hidden Finding or another Topic's citation cannot support the search.

With eligible options, read recent notes alongside the rated claims. With feedback, the cheap model selects an option number or skips. Without notes, use the first eligible option. A failed selection leaves the default searches available. The model uses the Scan owner's key, a deadline, bounded output and private telemetry. Exa receives the selected public terms. The sixth request can add up to ten results before deduplication.

Web and Expo use one film placeholder and preserve loaded video playback when a newer film becomes ready. The episode removal confirmation dismisses while its request runs. A page-scoped set hides pending and accepted removals across the season lists. A failed removal restores its own row. The server remains authoritative for deletion and playback cleanup.

Each Scan reserves web search before any paid request. Postgres holds its public search results and known spend until Temporal hands ingestion to review. A retry replays the saved result. If the original request was interrupted before it saved anything, the Scan reports that Source failure and leaves the allowance spent. Default queries start while the optional selection is running.
